# 🚂 Railway Quick Deploy

Deploy trong 5 phút! Xem hướng dẫn chi tiết: [RAILWAY_DEPLOY.md](RAILWAY_DEPLOY.md)

## 🚀 Quick Start

1. **Fork/Clone repo này**
2. **Login Railway**: https://railway.app/ (dùng GitHub)
3. **New Project** → Deploy from GitHub → Chọn repo này
4. **Add MySQL**: Click "+ New" → Database → MySQL
5. **Set Variables**: Copy MySQL credentials vào PHP service
6. **Import DB**: Upload file `Database/final_cw.sql`
7. **Generate Domain** → Done! 🎉

## ✨ Features

- ✅ PHP 8.2
- ✅ MySQL Database
- ✅ Auto-deploy from GitHub
- ✅ Free SSL/HTTPS
- ✅ No TRIGGER dependency (hosting-compatible)

## 🔧 Tech Stack

- Backend: PHP
- Database: MySQL
- Mail: PHPMailer
- Hosting: Railway.app
